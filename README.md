# SAP RESTful Application Programming Model
## Step by Step

This repository is intended for ABAP developers, who until now successfully avoided Fiori development.
ABAP RAP is a relative painless way to do it.

The repository contains
- a document with step by step instructions, how to create a working Fiori Application with 2-level data model, validations, automations, authorizations and automated unit testing
- an ABAPGIT .zip file, containing all the (tested and working) codes. From this you can just load all into your SAP HANA Application Server
